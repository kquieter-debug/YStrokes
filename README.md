# YStrokes(Android Application)

### A personal simple project with AI🤓

## File structure

```
ystrokes/
├─ lib/                      # Flutter source code
│  ├─ main.dart              # Main entry
│  └─ src/
│     ├─ app.dart            # Root widget
│     ├─ models/             # Stroke / DrawingProject
│     ├─ screens/            # welcome / home / canvas...
│     ├─ services/           # DrawingEngine / ProjectStore / SettingsService...
│     ├─ widgets/            # Custom widgets
│     └─ rust/               # flutter_rust_bridge
├─ rust/                     # Rust backend crate
│  ├─ Cargo.toml
│  └─ src/
│     ├─ lib.rs
│     ├─ api/mod.rs          # Rust API for Flutter
│     └─ frb_generated.rs    # Glue code generated by flutter_rust_bridge_codegen
├─ rust_builder/             # cargokit build glue（Rust → Android .so）
├─ android/                  # Android project
├─ assets/                   # Icon storage location
├─ flutter_rust_bridge.yaml  # codegen configuration
├─ test/                     # Flutter widget tests
└─ window/                   # Windows project（only for viewing rendering results and debugging）
```

## Requirements

- Flutter SDK（stable，Dart 3.x）
- Android SDK + **NDK**
- Rust Toolchain（`rustc` / `cargo`）+ `cargo-ndk`
- Android cross compilation targets
## For first time setup

```powershell
flutter pub get
cargo install cargo-ndk            # If not installed yet
flutter_rust_bridge_codegen generate   # Generate Rust → Flutter bindings
flutter run                        # Or flutter build apk
```

## After modifying Rust API

1. Edit `rust/src/api/mod.rs`。
2. Regenerate：`flutter_rust_bridge_codegen generate`。
3. Run rust tests：`cargo test --manifest-path rust/Cargo.toml`。

## Test

```powershell
cargo test --manifest-path rust/Cargo.toml   
flutter test                                  
flutter analyze                               
```
